# J.A.R.V.I.S. project instructions

Use Python/FastAPI in backend and React/TypeScript/Vite with R3F, Drei and React Three Postprocessing in frontend. Hermes is the sole agent runtime. The browser never calls Ollama directly. Do not claim hardware or provider compatibility based on contract fixtures.

Read docs/ARCHITECTURE.md and docs/SECURITY.md before changing integration or authorization. Preserve the separate native Hermes home. Do not modify global SOUL, Hyprland, Ollama service settings, startup units or external speech environments without explicit authorization. Keep local services bound to loopback. No hosted inference, cloud memory, telemetry exporters or public deployment.

Keep the web Hermes toolset limited to the reviewed plugin plus no_mcp. Do not weaken preflight to make a broad runtime pass. Model proposals cannot approve operations. Never introduce shell=True, arbitrary root execution or model-generated process argument arrays.

Native memory files belong to Hermes; use its guarded bridge. Keep proposals reviewable, deletions durable and session epochs server-owned. Never store raw microphone recordings or secrets as memories. Keep runtime data and model checkouts out of Git.

Run npm test and npm run build. Real browser checks: npm test -- --browser. In this restricted environment a separate temporary Chrome/CDP listener was needed; use --cdp only for reviewed QA. Real model diagnostics: npm test -- --hardware. Speech checks are separate and must not be advertised as passing when the selected voice import/synthesis fails.

Use the user-supplied holographic direction: original procedural WebGL geometry, near-black navy, restrained cyan/teal and amber failure states. Distinguish measured telemetry from decorative geometry. Reduce resolution/polling first when resources are tight, pause hidden-tab animation, and keep typed interaction available when voice fails.
